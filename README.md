Web server written in **C** with a modular and scalable architecture. It was originally 
developed as the last AP class project.

It explores system-level programming and HTTP server implementation. It also includes a 
custom **JSON-based logging system** inspired by NGINX, capable of handling client 
connections and serving static files efficiently.
